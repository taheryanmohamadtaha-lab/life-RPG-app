# Life RPG – ماجراجویی زندگی واقعی

اپ اندرویدی RPG برای تبدیل کارهای روزمره به ماموریت، XP، سطح، مهارت و پاداش. پیش‌فرض: فارسی (RTL) + تم فانتزی تاریک؛ انگلیسی و تم روشن اختیاری. کاملاً آفلاین.

`applicationId`: `com.liferpg.adventure` · Kotlin · Jetpack Compose · Material 3 · MVVM · Room · DataStore · Navigation Compose · WorkManager · Coroutines/Flow

## وضعیت صادقانه
کد کامل نوشته شده، اما **در محیطی که این پروژه ساخته شد امکان دانلود وابستگی‌های اندروید (Google Maven) وجود نداشت؛ بنابراین هنوز Build و تست روی آن‌جا اجرا نشده است.** مرجع واقعی، اجرای GitHub Actions است. تا زمانی که یک اجرای سبز در تب Actions ببینید، APK را «تأییدشده» فرض نکنید. اگر Build خطا داد، لاگ را در Issue بگذارید تا اصلاح شود.

## امکانات
- پروفایل قهرمان با ۷ ویژگی، منحنی XP (`60·L^1.3`، سطح ۱..۹۹)، عنوان و ظاهر تکامل‌یابنده
- ماموریت‌های روزانه/هفتگی/ماهانه/هدف/یک‌بار‌مصرف، ۵ سختی، ویرایش، تعویق، حذف
- ضد سوءاستفاده: جلوگیری از پاداش تکراری (ایندکس یکتا روی ماموریت+دوره)، سقف XP/سکه/جم روزانه، سقف بونوس
- درخت مهارت (۷ دسته، ۲۱ مهارت)، اقتصاد سکه/جم، فروشگاه پاداش واقعی دلخواه، کوله‌پشتی (۶ اسلات، ۶ کمیابی)
- دستاوردها، نقشه ۶ منطقه‌ای، پت اژدها با ۳ مرحله تکامل
- استریک بدون سرزنش (سپر و روز استراحت)، تقویم عادت، آمار، چالش روزانه و رویداد تصادفی
- صدا و انیمیشن، اعلان‌ها با ساعت سکوت، پشتیبان JSON (صادرات/وارد‌کردن با اعتبارسنجی) و ریست
- تب‌ها: خانه / ماموریت‌ها / نقشه / قهرمان / پروفایل + صفحات مهارت، کوله، دستاورد، آمار، تقویم، فروشگاه، تنظیمات

## ساخت APK
### با GitHub Actions (توصیه‌شده)
1. به تب **Actions** بروید و workflow «Android Build» را باز کنید (با هر push اجرا می‌شود؛ دستی هم با *Run workflow*).
2. پس از موفقیت، از بخش **Artifacts** فایل `LifeRPG-debug-apk` را دانلود و `app-debug.apk` را نصب کنید.

### محلی
JDK 17 و Android SDK 35 لازم است:
```
./gradlew testDebugUnitTest assembleDebug
```
خروجی: `app/build/outputs/apk/debug/app-debug.apk`

### نسخه Release امضاشده
کلیدها هرگز در سورس نیستند. در Settings → Secrets مخزن بسازید: `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`. با وجود `KEYSTORE_BASE64` workflow یک APK امضاشده هم می‌سازد.

## تست
تست‌های واحد در `app/src/test`: منحنی سطح، استریک، موتور تکمیل (سقف‌ها و بونوس)، کلید دوره‌ها، اقتصاد، مهارت، پشتیبان‌گیری.

## عیب‌یابی
- خطای SDK/دانلود: دوباره اجرا کنید؛ مشکل شبکه گذراست.
- نصب نشد: «نصب از منابع ناشناس» را برای فایل‌منیجر فعال کنید.
